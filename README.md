# Lab_1
Постановка:
Уплотнить строку S1, удалив символы, встречающиеся в строке S2.

Идея:
Для строки S2 создать ассоциативный массив, в котором индекс - номер символа ASCII, а значение - двоичное значение нужно ли этот символ удалять.
Затем, используя указатели - ptr_read и ptr_write, перезаписать исходную строку S1. Где читающий указатель смещается по исходной строке постоянно,
проверяя по ассоциативному массиву необходимость записи значения (встречается ли этот символ в строке S2), а пишущий указатель записывает 
значение в исходную строку, если оно не встречается в строке S2.

Тесты:
1. Классическая ситуация: "Helloh People!", "ople". Вывод: "Hh P!". Корректно.
2. Пустая строка s2: "abcdef", "". Вывод: "abcdef". Корректно.
3. Пустая строка s1: "", "abc". Вывод: "". Корректно.
4. Полное удаление строки s1: "aaaa", "a". Вывод: "". Корректно.
5. Несовпадающие строки: "abc", "xyz". Вывод: "abc". Корректно.
6. Разные регистры: "AaBb", "a". Вывод: "ABd". Корректно.
7. Удаление пробелов: "a b c", " ". Вывод: "abc". Корректно.
8. Дублированные символы в строке s2: "abcdef", "aabbcc". Вывод: "def". Корректно.
9. Удаление спец. символов: "Hello!", "!". Вывод: "Hello". Корректно.
10. Пустой указатель s1 "NULL". Вывод: "". Корректно. 
11. Пустой указатель s2 "NULL". Вывод: "". Корректно.

Тесты с кириллицей:
1. Удаление русских символов из русской строки: "привет", "п". 
	1.1 Программа отрабатывает строки по одному символу (байту), когда кириллистический символ занимает два, поэтому выходные символы искажаются.
	1.2 Из-за некорректного кодирования могут встречаться байты с одинаковыми кодами, поэтому программа их тоже будет удалять.
2. Исходная строка в русских символах, строка s2 - латиница: "привет", "privet".
	По причине описанной в 1.1 кириллические символы будут искажены.
3. Кириллическая строка и пустая строка s2: "привет", "".
	По причине описанной в 1.1 кириллические символы будут искажены.
4. Латинская строка s1 и кириллическая строка s2: "privet", "привет".
	Т.к. коды символов не совпадают программа отработает корректно и выдаст ответ: "privet".
5. Смешанная строка s1 и латинская строка s2: "как dela", "de".
	Кириллические символы будут искажены в силу 1.1, а латинские символы будут обработаны корректно.
