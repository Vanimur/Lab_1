# Lab_1
Постановка:
Дана непустая последовательность слов из строчных букв; между соседними словами – запятая, за последним словом – точка. Напечатать все слова из списка, содержащие ровно две буквы d.

Идея:
При прохождении по строке, проверять, является ли символ буквой или разделителем. Если символ - буква, то записать его начальный индекс и проверить
является ли символ буквой D. Если символ слова - буква D, то увеличить счетчик букв D. Как только встретился символ - разделитель, нужно проверить
значение счетчика буквы D, если он равен 2, то записать в выходной массив начальный индекс слова. После по начальным индексам слов вывести слова, удовлетворяющие условию задачи.

Рассмотренные тесты:
1. Пустая строка: "". Вывод: 0 слов найдено. Корректно.
2. Только разделители: ",,....,,". Вывод: 0 слов найдено. Корректно.
3. Слова без буквы 'd': "apple,banana,orange". Вывод: 0 слов найдено. Корректно.
4. Одно слово с двумя 'd': "dog,cat,doll". Вывод: 0 слов найдено. Корректно.
5. Слово с тремя 'd': "daddy,mom". Вывод: 0 слов найдено. Корректно.
6. Слово с двумя 'D' (разные регистры): "DaD,dog". Вывод: DaD. Корректно.
7. Несколько слов с двумя 'd': "add,,dad". Вывод: add dad. Корректно.
8. Слово после точки: ".add.". Вывод: Invalid input (-3). Корректно.
9. Недопустимые символы (цифры): "add,123,dad". Вывод: Invalid input (-1). Корректно.
10. Одно слово с двумя 'd': "dada". Вывод: dada. Корректно.
11. Слово с четырьмя 'd' и слово с двумя: "dddd,add". Вывод: add. Корректно.
12. Слова с двумя 'd' с пробелами: "add, dad". Вывод: add dad. Корректно.
13. Три слова с двумя 'd': "add,dad,ded". Вывод: add dad ded. Корректно.
14. Слова с двумя 'd' в разном регистре: "Dd,dd,Dd". Вывод: Dd dd Dd. Корректно.
15. Слова с двумя 'd' перед точкой: "Dd,dd,Dd.". Вывод: Dd dd Dd. Корректно.
16. Смешанные слова, точка в конце: "add,door,dad,data,added.". Вывод: add dad. Корректно.
17. Пробелы вокруг слов: "dad , ded.". Вывод: dad ded. Корректно.
18. Недопустимый символ после точки: "dad proba, add. f ". Вывод: Invalid input (-3). Корректно.
19. Нелатинские символы (кириллица): "тест". Вывод: Invalid input (-1). Корректно.
20. Нелатинские символы (кириллица), после корректного слова: " dad, проба ddd".  Вывод: Invalid input (-1). Корректно.
Входные данные:
Строка из слов анлийского алфавита, разделенных запятой, на конце точка. Также разделителем допускается пробел.

Выходные данные:
Если функция Find_words_with_two_d успешно завершила свою работу, то она вернет кол-во найденных слов и запишет в переданный её массив индексы слов.
Если же при выполнении задачи возникла ошибка, то функцию вернёт код ошибки в отрицательном диапазоне INT. Коды ошибок:
	-1 - найден символ не удовлетворяющий английскому алфавиту,
	-2 - передана пустой указатель,
	-3 - обнаружены символы после конца строки.
